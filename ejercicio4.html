Panel de Perfil Profesional

Este componente implementa propiedades modernas de CSS (Glassmorphism, color-mix(), @supports) garantizando una experiencia fluida y accesible en todos los navegadores.

Diseño Adaptable

Rejilla fluida mediante CSS Grid que se ajusta a dispositivos móviles y de escritorio.

CSS Moderno

Uso de @supports para detección de funciones avanzadas y paletas dinámicas.

Accesibilidad

Pausa o elimina las animaciones al detectar prefers-reduced-motion.

Informe de Compatibilidad

Navegador Resultado esperado y observado
Google Chrome (v110+) Soporte total para color-mix(), backdrop-filter y la detección mediante @supports. El degradado de cristal y los colores mixtos se renderizan sin fallos.
Mozilla Firefox (v113+) Visualización idéntica a Chrome. Soporte nativo de color-mix() y backdrop-filter sin requerir flags ni prefijos adicionales.

Fuente consultada: Documentación MDN (@supports) | CanIUse (color-mix)
